How It Works

Get started with multi-agent orchestration in 3 simple steps

Step 01

Create a Project

Start a new project and connect your AI agents. Claude, Cursor, Copilot, or any MCP-compatible agent integrates in one click.

Step 02

Assign Tasks

Create tasks on the Kanban board and assign them to agents. Each agent works in its own worktree in parallel, with zero conflict risk.

Step 03

Real-Time Locking

Symbol-level locking keeps agents synced automatically when working on the same code. Conflicts are detected and resolved instantly.
